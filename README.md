# Tixcash Explorer

Official blockchain explorer for the Tixcash network.

## Overview

Tixcash Explorer provides full transparency into the Tixcash blockchain, allowing users to:

- Search and verify transactions by hash
- Browse block history and block details
- View wallet addresses and balances
- Monitor validator and staking node activity
- Track token distribution and issuance

## Features

- Real-time transaction tracking
- Smart contract interaction history
- Staking and reward activity dashboard
- Network statistics (TPS, block time, active validators)
